# How to Update This Repo <!-- omit in toc -->
Each directory is a git submodule pointing to a GitHub repo. Two VS Code Copilot
skills automate adding new repos:

1. `/pull` — Run `python .github/skills/pull/scripts/fetch_repos.py` from the
   workspace root. This fetches all public non-fork repos from GitHub (2 API
   calls, no auth needed), filters out repos already in `.gitmodules` or the
   exclusion list, downloads READMEs, and creates `update.md` with metadata. The
   AI then classifies each repo (code vs non-code) and assigns categories. Use
   `--dry-run` to preview without writing files.
2. Review `update.md` — This is the human-in-the-loop step. Check categories,
   remove repos you don't want, fix descriptions, add notes.
3. `/push` — Reads `update.md`, adds each item to README.md under the correct
   `##` category section (as `###` entries with reference-style links), runs
   `git submodule add` for each repo, then verifies by re-reading both README.md
   and `.gitmodules` from disk.

**Key files:**
* `.github/skills/pull/SKILL.md` — Pull skill instructions
* `.github/skills/push/SKILL.md` — Push skill instructions
* `.github/skills/pull/scripts/fetch_repos.py` — Fetch script
* `.github/skills/pull/scripts/README.md` — Script documentation
* `.github/skills/pull/references/exclude-repos.md` — Repos to skip (one name per line)
* `update.md` — Generated by pull, consumed by push (not committed)
* `tmp/` — Script outputs: `new-repos.json`, `repo-info.json`, `repos.json`,
  `tmp/readmes/` (not committed)
